# 情動→書体の翻訳テーブル

ユーザーの情動選択から、書体系統と文房四宝（筆・墨・紙）を決定する内部ロジック。

## 情動の対比軸（5軸）

| 軸 | 選択肢 | キー名 |
|---|---|---|
| 重さ | 重い / 軽い | weight: heavy / light |
| 質感 | 硬い / 柔らかい | texture: hard / soft |
| 温度 | 熱い / 冷たい | temperature: hot / cold |
| 充満 | 満ちている / 空っぽ | presence: full / empty |
| 時間 | 今この瞬間 / 過去 / 夢のよう | time: present / past / dream |

ユーザーは複数選択可能。すべて未選択でも構わない（その場合は文字から推定）。

---

## 翻訳テーブル（主要パターン）

以下は、情動の組み合わせから書体系統への代表的な対応。**★印は実機検証で作品として成立を確認した組み合わせ**。それ以外は理論的な対応であり、可能性としてユーザーに提示する。実際の出力は試してみないと分からない。

| 情動の組み合わせ | 推奨書体系統 | 推奨アプローチ | 確認 |
|---|---|---|---|
| hard + cold | sokintai | 針金、痩金体、Freezing temperature | ★ |
| hard + cold + empty | zenei（テクスチャ型） | 乾いた茨、収縮、酸化色、テクスチャ系 | ★ |
| heavy + soft + hot | zenei（流体型） | 流体、垂れ落ち、高粘度 | ★ |
| light + empty + past | zenei（極限省略型） | 束ね筆、淡墨、虚無、息切れの掠れ | ★ |
| light + soft + cold + dream | wayou | 散らし書き、淡墨、雅 | ★ |
| soft + light + dream（短文） | gendai | 流体、潤渇、水の風景、章法解体 | ★ |
| soft + light + dream（長文） | gendai or kyousou | 章法解体長文、Image2推奨 | ★ |
| heavy + past + full | classical（メタリアリズム） | 多書体混在、鑑蔵印、古文書偽装 | ★ |
| hard + present + full（短い記号） | autograph | 高速運筆、鋭利な水平ストライク | ★ |
| light + soft + cold + empty | keitan | 自我を消した線、placement と silence | ★ |
| hot + present + full（破壊系） | zenei（爆発型） | 結体半解体、爆発的飛沫 | ★ |
| hard + hot + present | classical（顔真卿系） | 重厚な楷書、強い筆圧 | （可能性） |

★以外の組み合わせや、上に載っていない組み合わせの場合：

1. 最も近い★パターンを「類例」として提示する
2. 「あなたの組み合わせは未踏領域なので、実際に出力して確かめてみてください」と添える
3. 複数の方向が成立しうる場合は、ユーザーに「どちらに寄せたいか」を聞いてもよい

## 文房四宝の補足ルール

書体系統が決まったら、情動軸からさらに文房四宝（筆・墨・紙）を詳細化する。

### 筆
- **硬い系**（hard, cold）→ 細筆、枯筆、硬毫、束ね筆
- **柔らかい系**（soft, hot）→ 羊毛、長鋒、柔毫
- **流動系**（dream, soft + light）→ 破筆、墨継ぎなしの長鋒
- **autograph**：フレキシブルニブの万年筆、フェルトペン、ボールペン

### 墨
- **硬い系**（hard, cold）→ 濃墨、極濃墨、純黒
- **柔らかい系**（soft, dream）→ 淡墨、グラデーション豊富
- **解体系**（gendai, zenei の章法解体）→ 墨継ぎなしの渇筆、潤渇の極端な遷移
- **古典系**（classical）→ 標準的な濃墨
- **メタリアリズム**（classical 変則）→ 経年劣化を演出する茶褐色、酸化を模した色相

### 紙
- **硬い系**（sokintai, hard）→ 白く滑らかな紙、吸水性を抑制した紙
- **柔らかい系**（gendai 流体, kyousou）→ 吸水性の高い画仙紙
- **古典系**（classical, present）→ 標準的な画仙紙
- **メタリアリズム**（classical 変則）→ 経年劣化した黄ばんだ紙、虫食い・染みを伴うもの
- **和様**（wayou）→ 料紙（金銀箔散らし、雲母引き、唐紙）
- **枯淡**（keitan）→ 素朴な楮紙、無地の薄い紙
- **autograph**→ 厚手のカードストック、レターペーパー、色紙

### 参考書家

書体系統に対応する歴史的人物を1〜2名選定。詳細は `references/style_systems.md` の参考書家リストを参照。

## 「型」のラベリング

実機検証された★パターンには、便宜的に内部参照用の「型」名がついている。これらは Step 4 の方針提示や Step 5 の類例提示でユーザーに見せる名前として使える。ただし、これらは固有名詞ではなく**表現分類のラベル**であり、ユーザー自身のサンプルにも同じラベルを当てて良い。

| 型名 | 系統 | 特徴 |
|---|---|---|
| 痩金型 | sokintai | 針金状の極細線、Cold/Freezing |
| テクスチャ・物性型（咳型） | zenei | 乾いた茨、酸化色、収縮 |
| 流体・粘性型（洟型） | zenei | 高粘度、垂れ落ち |
| 虚無・極限省略型（一型） | zenei | 息切れの掠れ、画数の削ぎ落とし |
| 破壊・爆発型（闘型） | zenei | 結体半解体、爆発的飛沫 |
| 震動・墨継ぎ型 | zenei | 手の震えと墨継ぎの痕跡 |
| 概念視覚化型 | zenei | 文字を画像として分解再構築（風・波・雪） |
| 章法解体短文型（上善如水型） | gendai | 流体、潤渇、水の風景 |
| 章法解体長文型 | gendai | 章法解体しつつ書として成立 |
| 散らし書き型 | wayou | 平安和様、淡墨、料紙 |
| 枯淡型（祈型） | keitan | 自我を消した素朴な線 |
| メタリアリズム型 | classical（変則） | 多書体混在、鑑蔵印、古文書偽装 |
| マエストロ署名型 | autograph | 速度変化、フックと結節 |

これらの型名は、内部処理のラベルであり、Step 4 でユーザーに提示するときは必要なら平易な日本語に翻訳する。
