# 書体系統（8系統）

真理が扱う書体系統の分類とその境界、参考書家リスト。

## 系統別の特性

### sokintai（痩金体）
徽宗が発明した極細鋭利な線質。針金・金属ワイヤー・骨格構造を呼び出すための系統。Cold/Freezing の温度設定と相性が良い。物質性の「硬さ」を線質で表現するときの第一選択。

線の太さ：ヘアライン〜針金級。
墨：濃墨、純黒。
紙：滑らかで白い紙（吸墨性は抑制）。

### classical（古典正統）
顔真卿（重厚な楷書）、王羲之（典雅な行書）、欧陽詢（端正な楷書）、智永（千字文の正統学習）など、唐〜隋〜東晋の古典を中核とする。康煕帝・乾隆帝の書も含む。

**メタリアリズム変則**: classical 系統の特殊運用。複数書体・複数時代のコロフォン・鑑蔵印を画面に重ねて「古文書」としての説得力を演出する手法（後述の「メタリアリズム型」参照）。

筆：硬めの兼毫。
墨：濃墨。
紙：白〜淡黄色の画仙紙、または経年劣化した黄ばんだ紙（メタリアリズムの場合）。

### kyousou（狂草・流体系）
懐素・張旭・孫過庭の唐代狂草の本流。連綿（文字と文字をつなぐ筆の流れ）と章法（紙面全体の構成）が主役。文字単体の正確性は二次的で、流動性と速度が画面を支配する。

筆：長鋒の柔毫。
墨：やや薄めの墨、墨継ぎは大胆に。
紙：吸水性の高い画仙紙。

### gendai（章法解体・現代書系）
結体の崩しや章法の解体を使うが、**書として成立させる**ことを諦めない方向。読めて、空間が生きていて、かつ表現として強い。ウイスキー「響」のラベル、井上有一の初期〜中期の「読める作品」がここに属する。前衛のメソッドを取り込みつつ、書としての完結性を保つ。

筆：用途に応じて自由（硬毫〜長鋒）。
墨：潤渇の遷移を意図的に設計。
紙：画仙紙、または商業書なら厚手のアート紙。

### zenei（前衛書・抽象表現系）
墨人会・井上有一晩期・森田子龍の系譜で、文字を破壊して抽象表現に近づけ、ときに完全に文字を捨てる方向。書としての可読性や鑑賞性は二次的で、エネルギーや感情の物質化が主目的。

- 破壊・爆発系（「闘」のような怒り・燃焼の表現、結体半解体＋飛沫）
- テクスチャ・物性系（「咳」のような乾いた茨、酸化色、内側への収縮）
- 流体・粘性系（「洟」のような高粘度の垂れ落ち）
- 虚無・極限省略系（「一」のような息切れの掠れ、画数の削ぎ落とし）
- 震動・墨継ぎ系（手の震えと墨継ぎの痕跡を表現の核とする）
- 概念視覚化系（風・波・雪のように、文字を画像として分解再構築）

筆：破筆、束ね筆、零度墨（凍らせた墨）など特殊な道具。
墨：濃淡を極端に振る。墨継ぎなしでの渇筆も多用。
紙：吸水性の高い画仙紙、または特殊な基材。

### wayou（和様・連綿系）
平安期の散らし書き、料紙文化、淡墨の雅。小野道風・藤原行成の流れ。柔らかさ・軽やかさ・夢のような時間感覚と適合する。

筆：細い羊毛、または兼毫。
墨：淡墨。
紙：料紙（金銀箔散らし、雲母引きなど）。

### keitan（枯淡・無作為系）
弘一法師（李叔同）、良寛、八大山人晩年に代表される、技巧を捨てた素朴な線。**書き手の自意識が消える方向の到達点**で、classical でも zenei でもない第三の道。「自我のある書」（gendai, zenei）の対極にある。「祈」のような私心のない静かな文字に最も適合する。

筆：使い古した毛筆、あるいは細い葦筆。
墨：淡墨〜中墨。墨色のムラを許容。
紙：素朴な楮紙、または無地の薄い紙。

### autograph（署名・Maestro系）
アルファベットの署名・サインに特化した系統。マエストロ系の華麗な装飾、現代著名人サインの速度感、Western と Japanese のハイブリッドを含む。

ペン：フレキシブルニブの万年筆、フェルトペン、ボールペン。
速度変化：始筆（ゆっくり、太く）→中盤（高速、波線化、リエゾン）→終筆（大きなパラフ、空間支配）。
紙：厚手のカードストック、レターペーパー、色紙。

専用のプロンプト構造（speed_variation を含む）を持つ。`references/prompt_structure.md` の Section 7.2 参照。

## 境界判定（重要かつ繊細）

### gendai と zenei の境界

この区別は最も繊細で、判断ミスが起きやすい。

**gendai** は「書として成立させる」ことを諦めない方向。読めて、空間が生きていて、表現として強い。前衛のメソッドを取り込みつつ、書としての完結性を保つ。

**zenei** は文字を破壊して抽象表現に近づけ、ときに完全に文字を捨てる方向。可読性や鑑賞性は二次的で、エネルギーや感情の物質化が主目的。

**判定の補助線**：
- 「読める／読めない」が一つの目安だが、絶対ではない
- 「文字としての構造を保ちつつ崩す」が gendai、「文字を素材として解体する」が zenei
- 章法（画面全体の構成）を解体するのは gendai でも zenei でも起きるが、結体（一字の構造）まで破壊するなら zenei 寄り

### keitan の独立性

keitan は classical でも zenei でもない第三の道。技巧を捨てた素朴さに見えて、実は最も成熟した線。書き手の自意識が消える方向の到達点。「自我のある書」（gendai, zenei）の対極にある。

「祈」「静」「無」のような私心のない静かな文字には keitan が最も適合する。逆に、感情の強い文字（「闘」「怒」「叫」）に keitan を当てると弱い結果になる。

### classical のメタリアリズム変則

classical の通常運用は「正統な楷書・行書を端正に書く」だが、**メタリアリズム変則**は別物。複数書体（楷・行・草・隷など）、複数時代のコロフォン、複数の鑑蔵印を画面に重ねて、「古文書」「巻物」「鑑賞家を経た由緒ある作品」としての説得力を演出する。文字そのものより、**古文書という物質の説得力をシミュレート**することが目的。

長文（漢詩、宣言文、ニュース見出しなど）にメタリアリズムを当てると、「過去のもの／重い／満ちている」情動と強く共鳴する。

## 参考書家リスト

各系統に対応する歴史的書家・参照対象。Step 4 の方針提示時に1〜2名選んで「参考にする書家」として明示する。ユーザーが書家を知らない前提で、必要なら短く補足する。

| 系統 | 代表的な参考書家・参照対象 |
|---|---|
| sokintai | 徽宗（北宋皇帝、痩金体の発明者） |
| classical | 顔真卿（唐）、欧陽詢（唐）、王羲之（東晋）、智永（隋）、康煕帝、乾隆帝 |
| kyousou | 懐素（唐、狂草の代表）、張旭（唐）、孫過庭（唐、書譜） |
| gendai | 井上有一（中期）、手島右卿、商業書（響ラベル系）、20〜21世紀日本書家 |
| zenei | 井上有一（晩期）、森田子龍、フランツ・クライン |
| wayou | 小野道風、藤原行成、平安和様 |
| keitan | 弘一法師（李叔同）、良寛、八大山人晩年 |
| autograph | マエストロ系、現代著名人サイン |

### 書家紹介の書き方の例

ユーザーは書家を知らない前提。括弧書きで簡潔に補足する。

- 「徽宗（北宋の皇帝で痩金体という独特の書体を発明した人）」
- 「懐素（唐代の狂草の代表的な書家。連綿の流れが極端に強い）」
- 「弘一法師（李叔同とも。20世紀前半の中国の僧で、技巧を消した素朴な書を書いた）」
- 「井上有一（戦後日本の前衛書の代表者。文字を破壊して抽象表現に近づけた）」

専門用語（結体、章法、潤渇、墨継ぎ等）も初出時に括弧書きで補足：
- 「結体（一字の中での骨格と空間配置）」
- 「章法（紙面全体の構成）」
- 「潤渇（墨の濃淡と乾湿の遷移）」
