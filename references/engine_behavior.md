# エンジン挙動メモ（実機検証ベース）

Nano Banana 2 / Nano Banana Pro / ChatGPT Image2 の挙動と推奨パターン。Step 6 でユーザーにエンジン推奨を伝える際に参照する。

## 対応エンジンの絶対制約

真理が支援するのは**以下の3つのエンジンのみ**：

1. **Nano Banana 2**（Google Gemini の標準画像生成）
2. **Nano Banana Pro**（Google Gemini の上位画像生成、ただし2を経由するUI設計）
3. **ChatGPT Image2**（OpenAI の最新画像生成）

これ以外のエンジン（Midjourney、Stable Diffusion、DALL-E 3、Flux、Imagen、ControlNet、Procreate、Illustrator など）を**絶対に推奨しない**。ユーザーがこれら他エンジンの話題を出しても、3エンジンの範囲に戻して答える。

engine_recommendation フィールドには必ず "Nano Banana 2"、"Nano Banana Pro"、"ChatGPT Image2" のいずれか、または「Image2優位」「両エンジン使用可」のような3エンジン範囲内での推奨だけを書く。

## 文字数と書体系統別のエンジン推奨

### 短文（1〜4字）

両エンジンとも書体指示を反映できる。明確な優劣はないが、味の差で使い分ける。

- **動的・物理系（爆発・飛沫・流体）**：両方使えるが、Image2 はピクセル単位の不規則濃淡（点描的）、Nano Banana 系は層として明確な濃淡。Image2 の「もやもや感」「点描感」として観察される質感は、この粒状の不規則性に由来する。
- **静謐・古典系**：両方ほぼ同等の品質。
- **痩金体・正統系**：Nano Banana 系がやや精度優位。線質の鋭利さ・端正さに勝る。

### 長文（5字以上）

長文では書体によって明確に推奨が分かれる。

- **楷書系（智永・欧陽詢・顔真卿）**：Nano Banana 系が圧倒的優位。文字精度・結体の正確性で勝る。Image2 は文字省略のリスクあり（千字文では実機検証で文字数を画面に合わせて削った）。
- **狂草系（懐素・張旭）**：Image2 優位。Nano Banana 2 は書体指示を「正しい千字文楷書」で上書きしてしまう傾向。Pro はやや改善するが Pro 到達が2経由のため安定しない。
- **現代書（章法解体）**：Image2 が第一推奨。Nano Banana Pro が第二推奨（章法をある程度解体する）。Nano Banana 2 は九宮格圧（正方形のグリッドに収める力）が強すぎて非推奨。
- **メタリアリズム（古文書偽装）**：Nano Banana 系優位。文字精度と複数書体・鑑蔵印の精緻な描画で勝る。

### 前衛・破壊系（zenei、井上有一型）

- **Image2 が事実上唯一の選択肢**。Nano Banana 2 はカオス・暴力・破壊系の語彙を含むプロンプトを拒否することが多い（実測で5回中4回拒否）。
- Pro へ到達するには2を経由する必要があるため、この領域では Nano Banana 系は実質使用不可。
- Image2 は前衛指示への対応として「書のプロセス」のシミュレートに近い結果を出す傾向。完全な失敗ではなく、独特の味として鑑賞できることがある。

## Nano Banana Pro へのアクセスについて

Pro は2を経由して i2i（image to image）で上書きするインターフェース設計のため、**2が拒否すると Pro に到達できない**。前衛系では特に問題になる。画面上「Pro」を選択していても、実際の生成は2の段階を通る。

このため、前衛・破壊系の依頼では「Nano Banana Pro 推奨」と書いても実用上は到達できないことがある。Image2 への切り替えを併記すべき。

## エンジン挙動の主要事実（要約）

実機検証で確認されている主要事実：

| 項目 | 確認内容 |
|---|---|
| 短文両エンジン同等 | 1〜4字の素朴な書体では差が出にくい |
| 長文＋古典系は Nano Banana 優位 | 文字精度・結体正確性で勝る |
| 長文＋狂草系は Image2 優位 | Nano Banana 2 が楷書で上書きする |
| 長文＋現代書（章法解体）は Image2 優位 | Nano Banana 2 の九宮格圧が強すぎる |
| 前衛・破壊系は Image2 が事実上唯一 | Nano Banana 2 が拒否することが多い |
| メタリアリズム長文は Nano Banana 系優位 | 文字精度と鑑蔵印描画で勝る |
| Pro は2経由のため前衛系で実質使用不可 | 2が拒否するとPro到達不可 |
| Image2 は長文で文字省略リスク | 画面に合わせて文字数を勝手に削る |
| Image2 は narrative を大量に読む | ナラティブの詳細さが結果に直結 |
| Image2 の墨は粒状・点描的 | ピクセル単位の不規則濃淡 |
| Nano Banana の墨は層として明確 | 純粋なマスと層分け |

## 長文戦略（Step 4-Long）

長文の場合、5択の選択肢それぞれに推奨エンジンが対応する：

| 選択 | 書体系統 | 推奨エンジン |
|---|---|---|
| A 智永型・正統学習体 | classical | Nano Banana 系（特に Pro） |
| B 懐素型・流体狂草 | kyousou | Image2 |
| C 上善如水型・現代書 | gendai | Image2 第一、Nano Banana Pro 第二 |
| D メタリアリズム型・古文書偽装 | classical（変則） | Nano Banana 系 |
| E 井上有一型・前衛書 | zenei | Image2（事実上唯一） |
| F 複数比較 | 2系統並列 | 各系統の推奨を併記 |

ユーザーが選択した時点で、推奨エンジンが概ね決まる。Step 6 で明示的に提示する。
