# Shinri — 前衛書道プロンプト生成「真理」

支援するのは美文字（九宮格に収まる視認性最適化された文字）ではなく、表現としての書です。系譜としては黄庭堅、会津八一、そして商業書（ウイスキー「響」のラベル等）に見られる、結体で遊び、画面全体を3D空間として捉えた重心設計を志向します。
「人」を表現したいなら、ニンベンに墨をたっぷりつけ、本はかすれてさらさら済ませる——そういう倒錯した重み付けが書の表現です。基本構造を壊しながら空間としての塩梅を制御する、結体の操作。ここを支援するのが真理の役割です。

## これは何か

Shinri（真理）は、書道・カリグラフィの画像生成プロンプトを設計するスキルです。
Nano Banana 2 / Nano Banana Pro / ChatGPT Image2 向けに、
「表現としての書」——
結体で遊び、画面全体を3D空間として捉えた書——
のプロンプトを対話フローで組み立てます。

このスキルは画像を生成しません。
プロンプトを生成するだけで、
ユーザーは出力されたプロンプトを上記3エンジンのいずれかに投げる必要があります。

### 射程

**対象：**
- 漢字・仮名の書（一文字から長文まで）
- アルファベットの署名・サイン（gestural な手蹟）
- 黄庭堅、会津八一、商業書（ウイスキー「響」ラベル等）の系譜にある表現

**対象外：**
- 美文字（九宮格に収まる視認性最適化された文字）
  → 通常のフォントレンダリングや他のサービスを使ってください。
  Shinri はむしろこの領域を苦手とします。

## 限界の認識

2026年現在、LLMと画像生成エンジンは結体を真には壊せていません。
天衣無縫の書作品にはほど遠く、Shinri が提供できるのは
「ある程度の表現に至るための支援」です。

それでも、Nano Banana の「字」モードの暴発を、
8書体系統と5情動軸という尺度で制御することはできます。

## 八書体系統

| 系統 | 起源・性格 |
|---|---|
| **痩金体** | 宋徽宗の鉄線描き、骨格の純粋 |
| **古典正統** | 王羲之、智永、九成宮——基準としての書 |
| **狂草** | 張旭・懐素の即興、運動量による形の解体 |
| **現代書** | 近代以降の前衛、上善如水のような身体性 |
| **前衛** | 形そのものの解体、墨と空間の物質性 |
| **和様** | 仮名の余白、書としての日本性 |
| **枯淡** | 良寛の脱力、最小限の運筆 |
| **署名** | 個人の手蹟、gestural な記号性 |

詳細は `references/style_systems.md` を参照。

## 五情動軸

書を「気持ち」から逆算するための翻訳尺度：

- **重さ** — 墨量・運筆速度・線の太細
- **質感** — 筆毛・紙・かすれの構造
- **温度** — 墨の冷暖・筆触の硬軟
- **充満** — 空間の埋め方・余白の質
- **時間** — 即興か熟考か、ためか流れか

詳細は `references/character_analysis.md` と `references/translation_table.md` を参照。

## 使い方

### 1. アーティファクトとして使う（楽な方）

公開アーティファクト：
https://claude.site/public/artifacts/2bc9d68b-9da7-427d-a813-bdaec4735d47

claude.ai にログインして上記を開き、対話フローに従ってください。
冒頭分岐（漢字 or 署名）→ 文字入力 → 情動 → 方針 → 類例 → プロンプト出力、の流れです。

### 2. Claude Code の Skill として使う

`shinri.skill` をダウンロードして Claude Code に投入してください。
あるいは展開して `~/.claude/skills/` 配下に置けば自動ロードされます。

## フォルダ構造

```
shinri/
├── README.md
├── SKILL.md                    ← Skill エントリポイント
├── references/                 ← Skill が参照する補助知識（6本）
│   ├── character_analysis.md   ← 形声文字の分解・字源の運用
│   ├── engine_behavior.md      ← Nano Banana / Image2 の癖
│   ├── prompt_structure.md     ← プロンプト構造の組み立て方
│   ├── samples.md              ← 実例サンプル
│   ├── style_systems.md        ← 8書体系統の詳細
│   └── translation_table.md    ← 情動→書道パラメータの翻訳表
├── artifact/                   ← アーティファクト関連の素材
│   ├── Shinri_v6.jsx           ← アーティファクト本体ソース
│   ├── system_prompt.md        ← v3.1 システムプロンプト
│   ├── samples.json            ← 実例サンプル（19件）
│   └── images/                 ← 実例書道画像（19枚）
└── shinri.skill                ← Claude Code 投入用パッケージ
```

## 必要なもの

- claude.ai のアカウント（アーティファクト利用）、または Claude Code（Skill 利用）
- 出力したプロンプトを投げる先：Nano Banana 2 / Pro、または ChatGPT Image2
